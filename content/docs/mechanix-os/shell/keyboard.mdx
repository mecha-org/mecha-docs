Mechanix OS features a custom-built virtual keyboard designed specifically to meet the unique requirements of Mecha Comet device.

After testing several open-source solutions, we found that none of them met our performance and customization needs.
we have few requirements for the keyboard:
- Localization & Multi-language Support
- Embedded Optimization
- Deep Customization

None of the open-source solutions met our requirements, so we decided to build our own.

The Keyboard we built gives us the flexibility to make it exactly how we want it to be, and it is also optimized for embedded devices.

## Features

- Works with any input method engine, and it is also optimized for embedded devices.
- Works well with the cusom buit keyboard extension. this is huge requirement for us, to support the keyboard extension hat we built.
- Localization & Multi-language Support, Auto complete, and furter customization options.
- This is still in active development, and we are working on adding more features to it.
